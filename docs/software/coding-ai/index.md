# コーディングエージェント

コードの読み書きやコマンドの実行を AI に任せる、コーディングエージェントについてのメモ。
ツールごとのページ:

- [Antigravity](antigravity.md)
- [Claude Code](claude.md)

## 機能

多くのコーディングエージェントに共通する機能について、一部を取り上げる。

- ルール: エージェントに守らせる指示。ファイルごとに「どの作業のときに読み込むか」を決められる。
- スキル: 特定の作業の手順書。`SKILL.md` の説明(`description`)で、使うべき場面が判断され、必要になったときに本文が読み込まれる。

製品によって読み込むパスが異なる。以下は、プロジェクトルートからの相対パスである。

| 種類 | Claude Code | Antigravity |
| :--- | :--- | :--- |
| ルール | `.claude/rules/*.md`(フロントマターの `paths`) | `.agents/rules/*.md`(フロントマターの `trigger`) |
| スキル | `.claude/skills/<name>/SKILL.md` | `.agents/skills/<name>/SKILL.md` |

詳細は、各ツールのページを参照。

## 複数のツールで共通のコンテンツを使う

同じリポジトリを、複数のツールで扱うときは、実体を1か所にまとめて、各ツールのディレクトリから参照する方法がある。

- スキル: どちらのツールも `SKILL.md`(フロントマターの `name` と `description`)なので、実体のディレクトリへのシンボリックリンクで足りる。スキルごとにリンクを作る。実体は、プロジェクト直下の `skills/` に置く例が、よく見られる。
- ルール: 共通のルールの、標準的な置き方は、2026-11-21 時点では把握できていない。フロントマターの書式がツールごとに違うので、シンボリックリンクにはできない。方法の1つは、各ツールのディレクトリ(`.claude/rules/`、`.agents/rules/`)に、それぞれの書式のフロントマターと、実体への相対パスの参照だけを書いた実ファイルを置くこと。

### このリポジトリの例

このリポジトリ(tech-notes)では、ルールとスキルの実体を、`agent/` にまとめている。これは、このリポジトリ独自の置き方で、標準的なものではない。

```text
agent/rules/        ルールの実体
agent/skills/       スキルの実体
.claude/rules/      Claude Code 用のルールファイル(フロントマターと、実体への参照)
.agents/rules/      Antigravity 用のルールファイル(同上)
.claude/skills/     agent/skills/ の各スキルへのシンボリックリンク
.agents/skills/     同上
```

!!! note
    実体の内容を変えたときに、ルールの実ファイルを直す必要はない。ただし、適用の範囲(どのファイルを扱うときに読み込むか)を変えるときは、両方のツールの実ファイルを直す。
