# 記事の構成の変更

対象: ページの追加・削除・移動・大きな変更のとき。同期して更新するファイルは、`docs/**/*.md`、`zensical.toml`(`nav`)、`agent/index/**/*.md`(インデックス)。

## 操作ごとに更新するもの

| 操作 | `zensical.toml` の `nav` | `agent/index/` の項目 |
| :--- | :--- | :--- |
| ページの追加 | 追加する。`nav` には全ページを明記する | 追加する |
| ページの削除 | 削除する | 削除する |
| ページの移動・名前の変更 | パスを直す | パスを直す。移動先が別のインデックスファイルなら、項目も移す |
| 大きな変更(H2 の追加・削除、主題の変更) | 不要 | 概要を見直す |
| 軽微な修正(誤字、少しの加筆、H3 以下の小見出しの追加) | 不要 | 不要 |
| メモ(`docs/memo/`)の追加 | 追加する | 対象外(インデックスに載せない) |

- インデックスの項目の書き方と、更新の手順は、スキル `write-doc`(`agent/skills/write-doc/SKILL.md`)に従う。
- 日付のメモは、各年のフォルダの下に直接作る(例: `docs/memo/2026/20260101.md`)。年のフォルダがなければ、`index.md` も作り、`nav` に追加する。

## ページの分割

- 書いた結果、1ページが300行を超えるときは、分割を検討する。分割するかどうかは、ユーザーに提案して決める。
- 分割する場合は、ページの追加と移動にあたる。上の表に従い、`nav` とインデックスを更新し、記事間のリンクも直す。
- すでに300行を超えているページへの、軽微な修正では、提案しなくてよい。

## 更新後の確認

- `uv run python scripts/docindex.py check` がエラーなしで通る(`docs/` とインデックスの過不足、置き場所、概要の未記入がない)。
- `uv run zensical build --clean` でビルドが通る。
