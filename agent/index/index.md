# docs/ のトップレベルのインデックス

`memo/` は対象外。メモの作り方は `AGENTS.md` を参照。

## ディレクトリごとのインデックス

トップレベルのディレクトリごとに、1つのインデックスのファイルがある。1ファイルの目安は80ページまで。80ページを超えたら、`<dir>/` のディレクトリに分ける。

| ディレクトリ | インデックス | ページ数 | 主題 |
| :--- | :--- | ---: | :--- |
| `docs/cli/` | [cli.md](cli.md) | 26 | コマンドラインツール、シェル、UNIX 系コマンド |
| `docs/data-format/` | [data-format.md](data-format.md) | 1 | データ形式(JSON、Protocol Buffers など) |
| `docs/document/` | [document.md](document.md) | 3 | ドキュメントとドキュメンテーションツール(man、Markdown) |
| `docs/firmware/` | [firmware.md](firmware.md) | 3 | ファームウェア(BIOS、UEFI) |
| `docs/google/` | [google.md](google.md) | 27 | Google のサービス(GCP、Apps Script、Colab など) |
| `docs/network/` | [network.md](network.md) | 2 | ネットワーク、DNS |
| `docs/os/` | [os.md](os.md) | 6 | OS(Linux、macOS、UNIX) |
| `docs/program/` | [program.md](program.md) | 53 | プログラミング言語(Go、JavaScript、Perl、Python、Ruby、Rust) |
| `docs/security/` | [security.md](security.md) | 2 | セキュリティ、データの符号化 |
| `docs/software/` | [software/index.md](software/index.md) | 82 | ソフトウェア製品(Docker、Git、Kubernetes、Terraform、エディタなど) |
| `docs/web-service/` | [web-service.md](web-service.md) | 15 | Web サービス(AWS、GitHub、Datadog、Slack など) |

`docs/` 直下のページは、このファイルの下に載せている。
